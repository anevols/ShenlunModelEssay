# 申论范文生成器 · 分阶段实施计划

> 配套文档：申论范文生成工作流计划（调度 → 生成 → 封装 → 校验 → 归档 → 聚合）
> 本文档按时间线拆解为 4 个 Phase，每个 Phase 含明确交付任务。

---

## Phase 1：基础框架（Week 1–2）

- [ ] 搭建项目目录结构与依赖管理
- [ ] 实现主题配置加载器（topics.json 解析）
- [ ] 实现基础 LLM 调用封装（支持 OpenAI/Claude/本地模型）
- [ ] 编写系统 Prompt 模板与动态 Prompt 组装器
- [ ] 实现基础 HTML 模板（Jinja2），支持内联样式与 JS 注入
- [ ] 实现文件存储与目录归档逻辑

**交付目标：** 跑通「指定主题 → 调用 LLM → 输出 HTML 文件」最小闭环。

---

## Phase 2：生成引擎（Week 3–4）

- [ ] 实现结构化生成：Prompt → JSON Schema → 范文数据
- [ ] 实现句子级标注自动分类（基于 arg_type）
- [ ] 实现 HTML 渲染器：将 JSON 转换为完整单文件 HTML
- [ ] 实现 meta 标签自动注入（title, article-title, category, order）
- [ ] 实现批量生成任务队列（支持并发控制）
- [ ] 实现生成日志与任务状态追踪

**交付目标：** 批量生成结构化范文，每篇含完整标注与 meta，可被阅读站解析入库。

---

## Phase 3：质量校验（Week 5）

- [ ] 实现结构校验：五段三分式检测
- [ ] 实现字数校验：1000–1200 字范围检测
- [ ] 实现论证标注覆盖率检测（≥5 种 arg_type）
- [ ] 实现案例数量检测（≤3 处 case）
- [ ] 实现 span 标签完整性检测（class, onclick, data-text）
- [ ] 实现校验失败自动重试机制（最多 3 次）
- [ ] 实现校验报告生成

**交付目标：** 生成后自检，不达标自动重生，输出批次质量报告。

---

## Phase 4：高级功能（Week 6–7）

- [ ] 实现主题轮换策略（轮询 / 随机 / 优先级）
- [ ] 实现案例素材库管理（增删改查 + 自动注入）
- [ ] 实现生成历史去重（基于标题/内容相似度）
- [ ] 实现自定义样式主题切换（白色简洁 / 纸质 / 深色）
- [ ] 实现生成进度实时监控（WebSocket / SSE）
- [ ] 实现生成结果预览与人工干预接口

**交付目标：** 生产级能力，支持素材库管理、去重、实时监控与人工干预。

---

## 与现有系统的集成点

| 集成点 | 说明 |
|---|---|
| 十大板块 | 复用 `server/categories.py` 与 `web/src/shared/constants.js` |
| HTML 解析 | 生成的 HTML 须符合 `web/src/admin/utils.js` 的 `parseHtmlFile` 规则 |
| 交互 JS | `toggleAnalysis` 与 `web/src/analysis.js` 保持一致 |
| 文章入库 | 可选：生成后调用 `POST /api/articles` 自动入库（需管理员 token） |
| 侧边栏分类 | meta `article-category` 必须属于十大板块，否则排到「未分类」 |
