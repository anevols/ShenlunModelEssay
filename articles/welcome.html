欢迎来到阅读空间

2024-01-15 · 站长

这是一篇示例文章。整个站点的运作方式非常简单：

如何发布新文章

  1. 在 articles/ 目录下新建一个 .html 文件。
  2. 复制本文件的 <head> 中的几行 <meta> 标签，填写标题、日期、摘要、作者、标签。
  3. 在 .article-content 容器里写正文。
  4. 提交并推送到 GitHub，几秒后首页就会自动列出这篇新文章。

为什么不需要手动维护索引

首页通过 GitHub Contents API 列出 articles/ 目录下的所有 .html 文件，再读取每个文件 <meta> 中的元信息，渲染成卡片。所以只要文件在目录里，它就会被发现。

注意：未认证的 GitHub API 每小时限 60 次请求。个人站点足够使用；如果你希望提高限额，可在 js/main.js 中加入一个只读 token。

正文支持的元素

标题、列表、引用、行内 代码 都已经预设好样式：

// 代码块示例
function hello(name) {
  console.log(`Hello, ${name}!`);
}

链接也支持：GitHub Pages 官方文档。
